Como Jogar

  1. Escolham juntos as categorias e o nível de intensidade.
  2. A cada rodada, um de vocês recebe uma carta aleatória.
  3. Leiam o desafio em voz alta e vivam o momento juntos.
  4. Usem Próximo para avançar, Outra para trocar de carta, ou Pular para ignorar.
  5. A pontuação é opcional — somem pontos quando completarem um desafio.
  6. O jogo alterna automaticamente entre os dois jogadores.

Joguem com consentimento, leveza e respeito. O objetivo é a conexão.
